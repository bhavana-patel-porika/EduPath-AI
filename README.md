# EduPath AI
AI-Based Backlog Exam Preparation & Career Roadmap

## Team
Dream2Build — CareerX Origin HackFest 2026

## Overview
EduPath AI helps students organize backlog exam preparation
and create personalized career learning roadmaps.

## Features
- Personalized study timetable with daily time slots
- Exam countdown and revision planning
- Notes, learning resources, and recommended classes
- Career pathway suggestions and skill-gap analysis
- Recommended courses and duration-based learning roadmap

## Live App
https://edupath-ai-backlog-exam-prep-career-roadmap.ai.studio/

## Development
Developed using Google AI Studio.

## Limitations
Plans and recommendations are guidance, not guaranteed
academic results or employment outcomes.
